# AI Hallucination Mitigation — Frontend

## Overview

The frontend is the user-facing web application for the AI Hallucination Mitigation System.

It provides an interface for submitting questions and viewing evidence-grounded responses generated by the backend RAG and verification pipeline.

The interface is designed to make the verification process understandable by displaying:

- User queries
- Generated answers
- Verification status
- Confidence score
- Retrieved evidence
- Source information
- Verification claims
- Knowledge graph information
- Query history
